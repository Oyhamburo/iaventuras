# IAventuras

Juego local de preguntas sobre inteligencia artificial para equipos.

## Incluye

- 25 preguntas revisadas divididas en 2 niveles de dificultad.
- Ruleta para elegir quién responde.
- Progreso de preguntas por nivel para evitar repeticiones.
- Identificación de la respuesta correcta y explicación después de cada intento.
- Diseño responsive con monstruitos, sin recursos externos.
- Guardado automático de nombres y progreso en el navegador.

## Abrir el juego

La forma más simple es abrir `index.html` con doble clic.

También se puede levantar un servidor local desde esta carpeta:

```bash
python3 -m http.server 8000
```

Después, abrir [http://localhost:8000](http://localhost:8000).

No hace falta instalar paquetes ni tener conexión a internet.
